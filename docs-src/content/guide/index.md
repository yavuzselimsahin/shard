The [Quick start](/quick-start/) gets one command running. This section covers
the rest: describing your machines, choosing which of them to use, splitting a
long list of work between them, and finding what happened afterwards.

Read it in order, or jump to what you need:

- [The cluster file](/guide/cluster-file/) — every option a machine can have.
- [Shipping your code](/guide/shipping-code/) — running a script on machines
  that do not have it yet.
- [Running commands](/guide/running-commands/) — `shard exec` and its options.
- [Sharing work out](/guide/sharing-work/) — one job list, several machines.
- [Running one thing many times](/guide/many-runs/) — the same command with a
  changing number.
- [Steps and pipelines](/guide/pipelines/) — different commands, in order or
  side by side.
- [Named jobs](/guide/tasks-file/) — `tasks.toml`, so you type the name
  instead of the command.
- [Queueing jobs](/guide/queue/) — line several up and let them run in
  priority order.
- [Logs and history](/guide/logs-and-history/) — where the output goes.
- [The web dashboard](/guide/web-dashboard/) — watching a run in a browser.
- [The terminal dashboard](/guide/terminal-dashboard/) — the same, without
  leaving the terminal.
