Guide

The Quick start gets one command running. This section covers the rest: describing your machines, choosing which of them to use, splitting a long list of work between them, and finding what happened afterwards.

Read it in order, or jump to what you need:

  • The cluster file — every option a machine can have.
  • Shipping your code — running a script on machines that do not have it yet.
  • Running commands — shard exec and its options.
  • Sharing work out — one job list, several machines.
  • Running one thing many times — the same command with a changing number.
  • Steps and pipelines — different commands, in order or side by side.
  • Named jobs — tasks.toml, so you type the name instead of the command.
  • Queueing jobs — line several up and let them run in priority order.
  • Logs and history — where the output goes.
  • The web dashboard — watching a run in a browser.
  • The terminal dashboard — the same, without leaving the terminal.
